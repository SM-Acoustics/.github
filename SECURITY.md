# Security Policy

If the affected repository offers GitHub **Private Vulnerability Reporting**, use its Security tab. Do not publish exploits, credentials, vulnerability details or personal data in public issues.

If private vulnerability reporting is unavailable, contact a project maintainer through an independently verified private channel before disclosure. This document does not claim that a particular inbox or vulnerability-reporting feature is enabled.

Support windows and remediation targets are defined per product release. Security claims require reproducible validation. Embedded audio threat models include supply-chain tampering, OTA/rollback, network control, unsafe output levels, loudspeaker damage, DMA memory faults and untrusted presets.
