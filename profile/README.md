# SM Acoustics

**Research · Audio Computing · Embedded Systems**

We build reusable audio computation technology for synthesizers, speaker DSP, live mixing, spatial sound, audio plugins and embedded devices.

Architecture: **Rust portable DSP and explicit contracts, with independently qualified platform adapters** for desktop, WebAssembly, Android, plugins, ESP32 and future STM32 boards.

[Engineering governance](https://github.com/SM-Acoustics/.github) · [PROPHET-XII reference synthesizer](https://github.com/SM-Acoustics/prophet-xii)
