# ADR-0004 — No silent code moves or relicensing

Status: Proposed; Date: 2026-11-13.

## Decision
Repository transfer, code extraction and institutional adoption require verified provenance, copyright ownership/permission, applicable license conditions and explicit maintainer-reviewed migration. Existing GPL-only and GPL-or-later code cannot automatically be treated as permissively reusable. Keep independent proprietary-firmware research separate from the SM Acoustics institution.

## Rationale
Reusing a stable feature is desirable, but distributing incompatible or unauthorized code introduces legal and supply-chain risk. Architectural naming and organization ownership do not supersede licenses or contributor rights.
